# DIRMS 1.0

The PHP/MySQL application is in **[`DIRMS/`](DIRMS/README.md)**. That directory is
the folder to copy into your XAMPP `htdocs` directory.

Read the application README for fresh installation, safe database upgrades,
incident tracking, security configuration and testing. Existing installations
must back up their database and evidence before running `upgrade.php`; do not
import a new schema over existing data.
